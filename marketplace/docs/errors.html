Errores comunes

“extension.json requiere id, name y version”

Falta uno de los tres campos obligatorios o el archivo no contiene JSON válido.

“Ese ID ya pertenece a otro repositorio”

Ese identificador ya fue publicado desde otra URL de GitHub. Usa el repositorio original o un ID diferente.

“Publica una versión mayor que…”

Incrementa el valor de version antes de volver a publicar.

“GitHub no permite objetos Git normales mayores de 100 MiB”

Ese archivo supera el límite aplicado por GitHub para un objeto Git normal. Reduce su tamaño o usa un mecanismo de distribución apropiado para archivos grandes.

“El repositorio debe ser público”

Cambia la visibilidad del repositorio a pública antes de enviarlo a la marketplace.

“AxiomGuard bloqueó la extensión”

El análisis encontró un indicador crítico, un tipo de archivo ejecutable no permitido o una combinación de comportamientos de alto riesgo. Elimina ese comportamiento y vuelve a analizar el repositorio.

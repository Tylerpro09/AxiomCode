Conectar AxiomCode Marketplace a otros editores de código

AxiomCode Marketplace no está limitada al editor AxiomCode. Otros editores, IDEs o herramientas pueden consumir el catálogo público, comprobar versiones y descargar los archivos de una extensión mediante HTTPS.

Compatibilidad: conectar la tienda permite descubrir y descargar extensiones. Para ejecutarlas, el otro editor debe implementar las contribuciones y APIs que use cada extensión. Una extensión creada específicamente para AxiomCode puede requerir una capa de compatibilidad en el editor externo.

Endpoint principal del catálogo

GET https://axiomcode-marketplace.onrender.com/api/catalog

La respuesta usa schemaVersion: 1 e incluye el array extensions.

{
  "schemaVersion": 1,
  "name": "AxiomCode Marketplace",
  "extensions": [
    {
      "id": "autor.mi-extension",
      "name": "Mi extensión",
      "version": "1.2.0",
      "description": "...",
      "publisher": "Autor",
      "tags": ["editor"],
      "install": {
        "kind": "files",
        "files": [
          {
            "path": "extension.json",
            "url": "https://raw.githubusercontent.com/...",
            "size": 1200
          }
        ]
      }
    }
  ]
}

Integración mínima en JavaScript

const MARKETPLACE =
  'https://axiomcode-marketplace.onrender.com/api/catalog';

async function obtenerExtensiones() {
  const response = await fetch(MARKETPLACE);
  if (!response.ok) throw new Error('Marketplace HTTP ' + response.status);

  const catalogo = await response.json();
  return catalogo.extensions;
}

const extensiones = await obtenerExtensiones();

for (const extension of extensiones) {
  console.log(
    extension.id,
    extension.version,
    extension.install?.kind
  );
}

Instalar una extensión desde otro editor

  1. Consulta /api/catalog.Busca la extensión por su id.
  2. Compara la versión.Si la versión del catálogo es mayor que la instalada, ofrece Actualizar.
  3. Lee install.kind.Las extensiones de comunidad normalmente usan files. Las extensiones bundled forman parte de AxiomCode y no son un paquete independiente.
  4. Descarga cada archivo.Usa la URL HTTPS de install.files y conserva la ruta relativa indicada por path.
  5. Valida el paquete.Comprueba extension.json, ID, versión y cualquier hash disponible antes de activar la extensión.
  6. Ejecuta tu propia capa de seguridad.Se recomienda aplicar un análisis equivalente a AxiomGuard antes de cargar código de terceros.

Detectar actualizaciones

if (versionRemota > versionInstalada) {
  mostrarBotonActualizar();
}

Para producción, el editor externo debe usar una comparación de versiones semántica y no una comparación alfabética simple.

Otros endpoints públicos

EndpointMétodoUso
/api/catalogGETCatálogo de extensiones para AxiomCode u otros editores.
/api/inspectPOSTAnaliza un repositorio GitHub antes de publicarlo y devuelve también el resultado de AxiomGuard.
/api/publishPOSTPublica una extensión válida desde un repositorio GitHub público.
/api/editor/latestGETÚltima release oficial del editor AxiomCode.
/healthGETEstado del servicio Marketplace y de sus capas de seguridad.

Actualizar una extensión

Para publicar una nueva versión, usa el mismo repositorio y conserva el mismo id.

  1. Modifica tu extensión.
  2. Aumenta version, por ejemplo de 1.0.0 a 1.1.0.
  3. Haz commit y push a GitHub.
  4. Vuelve a pegar la misma URL en la sección Publicar.

Cuando AxiomCode detecte una versión mayor, mostrará la opción Actualizar a los usuarios que tengan la extensión instalada.
